# data/

Nothing here except this file is in git. Back the folder up separately (it holds the only copy of
the hand-fixed labels).

## Layout

```
data/
  captures/<session>/      raw full frames from `capture`, PNG: 0001.png and on (the record)
    session.toml           date, lighting, notes, camera settings, mount, plate corners, and
                           each frame's kind (resistors, mixed = with non-resistor objects)
    rectify.json           the session's calibration, from the empty-plate frame
    rectified/             white-balanced top-down copies, for looking at; regenerate with
                           `rectify apply`
  backgrounds/<session>/   empty-plate frames from the same session (0001.png from `capture`)
  live/                    frames saved from `live` with S
  cutouts/                 resistor body cut-outs: <id>.png (RGBA) and <id>.json (polygon, package)
  synthetic/<name>/        frames from `synth`, JPEG (like the camera's MJPG), plus preview/
                           with the labels outlined; re-running `synth` with the same name
                           replaces the set, `clean_synth` deletes sets
  manifest.json            every labelled frame
  yolo/                    generated by `export_yolo`; safe to delete
```

A session is one sitting with the camera, backdrop and lighting unchanged. Name it
`YYYY-MM-DD_<letter>`, e.g. `2026-10-14_a`.

## manifest.json

The single source of truth for labels. Polygons are in full-frame pixel coordinates (not tile, not
normalised), matching the robot repo's `outline_px`.

```json
{
  "version": 1,
  "rules_version": 1,
  "samples": [
    {
      "image": "captures/2026-10-14_a/0001.png",
      "session": "2026-10-14_a",
      "source": "real",
      "width": 4608,
      "height": 2592,
      "instances": [
        {"polygon": [[1203.0, 840.5], [1265.0, 838.0], [1266.5, 862.0], [1204.0, 864.5]],
         "label_source": "auto"}
      ]
    }
  ]
}
```

- `source`: `real` or `synthetic`.
- `label_source`: `auto` (from `autolabel`, unchanged), `manual` (drawn or fixed by hand),
  `synthetic` (exact, from `synth`).
- Splits are not stored here. `configs/dataset.toml` assigns whole sessions to val and test.
